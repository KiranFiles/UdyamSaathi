# Sunita in three minutes

**Before presenting:** start the full-stack app with `DEMO_MODE=true`. Use only the included fictional samples. Choose Hindi or English before starting; generated draft text uses the language selected at processing time.

| Time | Show | Say |
|---|---|---|
| 0:00–0:25 | Home → **Load Sunita demo**. Point to the Hindi transcript and three attachments. | “Sunita makes papad at home in Indore. She can say ‘40–50 hazaar a month’ instead of filling out a form.” |
| 0:25–0:55 | Check consent, prepare drafts, and expand the document and form cards. | “One agent structures her story, another reads the evidence. The app exposes what it checked, not just a spinner. The ID number is masked.” |
| 0:55–1:25 | Open results → Paperwork. Show **90%** and the missing bank proof. Confirm the owner name. | “Reporting a bank account is not proof. The field stays empty until she has the evidence. Confirming a field does not submit an application.” |
| 1:25–1:55 | Schemes → two sample matches; then Loan → **62/100** and three tips. | “Rules decide the matches and score. AI can explain them, not add an invented scheme or approve a loan. Verify real programmes with official sources.” |
| 1:55–2:25 | ONDC catalogue → show three products. Edit one price and save. Open Reminders. | “Sunita can correct a bilingual listing before it goes anywhere. The calendar suggests review routines, not legal deadlines.” |
| 2:25–3:00 | Download PDF, point out WhatsApp’s counts-only summary, then **Delete my data**. | “She leaves with a draft she controls. Nothing was filed, published or sent to a lender.” |

**Rehearsal fallback:** use `npm run dev` with the same `.env.local` if the Vercel CLI is not linked. The cached Sunita walkthrough does not need a cloud model, camera or microphone. An owner’s live session never borrows Sunita’s values.
